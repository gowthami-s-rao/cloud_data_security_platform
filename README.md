A unified Cloud Data Security Platform (CDSP) integrating Multi-Cloud Policy Engine, Dynamic ABAC, Inline Cryptographic & PII Pipeline, Just-In-Time (JIT) Key Management, and Centralized Security Telemetry.

## Run Locally

**Prerequisites:** Node.js (v18+)

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the app:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) in your browser.
